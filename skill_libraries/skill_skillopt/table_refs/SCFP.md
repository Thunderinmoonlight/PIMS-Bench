
# SCFP (Scanfiner Parameters)
- Contains Scanfiner unit configuration
- Column 'MAX' controls the maximum capacity limit
- To enable Scanfiner: set MAX column to 5 for the relevant row
- Row identifiers typically use unit codes (e.g., 'SCANFINER', 'SCF')
- Use write_sheet(sheet_name='SCFP', ...) to modify values
