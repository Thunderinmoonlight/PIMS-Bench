
# SGTU Scenario Tables

## Sheet Name
- The SGTU scenario data is stored in the sheet named **SGTU** (not STGT or other variants).

## Key Parameters and Locations
- **Scanfiner MAX**: Located in the SGTU sheet, typically under a section for unit capacity limits. Look for rows/columns labeled 'Scanfiner' or 'SCF' with a MAX field.
- **Coker MAX**: Located in the SGTU sheet, under coker capacity limits. Look for rows/columns labeled 'Coker' or 'DCU' with a MAX field (expand to 25 for DCD supply).
- **JET product -> set to desired price).

## Usage
When performing an 'SGTU transplant', read the entire SGTU sheet to understand the scenario structure, then apply the specified parameter changes to the active case by modifying the corresponding cells.
