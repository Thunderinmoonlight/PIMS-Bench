
# Blends Table

## Purpose
Contains blend header information for gasoline blending operations.

## Key Columns
- **BLEND**: Blend ID/name
- **BLNDTYP**: Blend type (e.g., Regular, Premium)
- **VOLUME**: Blend volume target
- **STATUS**: Blend status (Active/Inactive)

## Related Tables
- **Blnmix**: Blend component recipes/mixtures
- **Blnspec**: Blend quality specifications
- **Buy**: Component purchase availability
