
## REF Sheet - Reformer Unit

### Purpose
Contains Reformer unit configurations including Research Octane Number (RON) ranges, capacity limits, and unit pricing.

### Key Columns
- **RON Range**: Operating octane number range (e.g., 98-110)
- **Capacity**: Maximum throughput capacity (in bbl/day or kt/year)
- **UPR Price**: Unit processing rate price (in $/bbl or $/ton)

### When to Use
- Task mentions 'Reformer' or 'RON' with a numeric range
- Task requires reformer capacity or pricing information
- Task ID contains 'REF' or scenario describes catalytic reforming
