
## WS-L4-02: SGTU Transplant with Scanfiner/Coker/JET

### Steps
1. Open sheet 'STGT' (note: tasks may say 'SGTU' - use 'STGT')
2. Open sheet 'CAPS' (case-sensitive, all uppercase)
3. In CAPS, locate Scanfiner row and set MAX column to 5
4. In CAPS, locate coker row and set MAX column to 25 (for DCD supply)
5. Open sheet 'SELL'
6. In SELL, locate JET product and set price to $155
7. Verify all changes and save
