
# DHT - Diesel Hydrotreater

## Equipment Tag
- **Tag**: SDHT (or the correct tag from the model)

## Key Tables
- **CAPS**: SDHT row for capacity limits
- **Yield**: YDHT or SDHT sheet for yield structure
- **Process Limits**: ProcLim sheet for SDHT constraints

## Yield Loss Modification
To improve hydrotreating yield (~1% less loss):
- Locate the yield loss row in the SDHT/YDHT table
- Reduce the loss factor by approximately 1% (e.g., if current loss is 2.5%, change to 1.5%)
- This typically involves modifying the yield of light ends or gas products downward
