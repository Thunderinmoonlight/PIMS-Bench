
## Coker Capacity
- Table: CAPS
- Column: MAX
- Row identifier: Equipment = CKR (or Coker unit name)
- Usage: To set coker maximum throughput, modify MAX value in CAPS table for the coker row.

## KD1 CD1 Swing
- Table: DELTA (or SWING)
- Column: CD1
- Row identifier: KD1 operating mode delta vector
- Usage: To modify K/D swing, adjust the CD1 value for the KD1 delta vector row. CD1=7 means set the CD1 coefficient to 7.
