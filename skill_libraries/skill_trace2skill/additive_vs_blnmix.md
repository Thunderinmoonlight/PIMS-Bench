# Lesson: ADDITIVE vs BLNMIX Table Selection

Observed: Agents confuse additive changes with blend component changes.
- BLNMIX: bulk blend components (crude fractions like DCD, HCD, RFT)
- ADDITIVE: trace chemicals (TEL, ethanol, dye, MTBE)

Rule: "Enable DCD blending" -> BLNMIX. "Add TEL to gasoline" -> ADDITIVE.
