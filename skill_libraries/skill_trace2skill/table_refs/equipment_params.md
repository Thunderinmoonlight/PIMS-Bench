
# Equipment Parameter Sheets

## Coker
- Sheet: COKER
- Parameters: MAX (capacity), PRICE, KD1 (K swing), CD1 (D swing)

## DSL (Diesel Hydrotreater)
- Sheet: DSL
- Parameters: MAX (capacity), PRICE, KD1 (K swing), CD1 (D swing)

## General Rule
- K/D swing parameters (KD1, CD1) are always in the equipment's own sheet
- Capacity (MAX) and economic (PRICE) parameters are also in the equipment's own sheet
