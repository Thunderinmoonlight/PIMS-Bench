# Swing Sheet

## Purpose
Defines K/D (knockdown) swing parameters for process units.

## Key Columns
- **KD1**: Knockdown parameter 1 (modifiable)
- **CD1**: Cycle duration parameter 1 (modifiable)

## Modification Instructions
To modify K/D swing parameters:
1. Read the 'Swing' sheet to identify the target row
2. Use write/edit operations to update KD1 and CD1 values
3. Example: Set KD1=7, CD1=7 for the specified unit
